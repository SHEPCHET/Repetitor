## Повторная проверка

В терминале папки проекта:

```powershell
.\.venv\Scripts\python.exe -B -X utf8 run_checks.py
.\.venv\Scripts\python.exe -B -X utf8 benchmark.py --output performance-local.json
```

Для повторного запуска Black и flake8 можно установить бесплатные инструменты:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m black --check .
.\.venv\Scripts\python.exe -m flake8 .
```

Для обычного запуска программы эти инструменты не нужны.
